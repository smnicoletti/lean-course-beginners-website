Lezione 6: Tipi induttivi, ricorsione e induzione

1. Scopo della lezione

In questa lezione definiamo tipi con una struttura esplicita, funzioni ricorsive sui loro valori e dimostrazioni per induzione. Vediamo anche rfl, unfold, rw e simp.

2. Tipi induttivi

Nelle lezioni precedenti Cosa : Type lasciava aperta la struttura del dominio. Un tipo induttivo elenca invece i modi in cui possiamo costruire i suoi valori: questi modi si chiamano costruttori.

inductive Semaforo where
  | rosso
  | giallo
  | verde

I tre costruttori descrivono tutti i valori possibili di Semaforo. Possiamo definire un predicato mediante pattern matching:

def SiDeveFermare : Semaforo → Prop | .rosso => True | .giallo => True | .verde => False

Il pattern matching specifica il risultato per ciascun costruttore. Per ragionare su ogni semaforo, cases s apre i tre casi rosso, giallo e verde.

theorem lecture06_semaforo_ha_un_colore (s : Semaforo) : s = .rosso ∨ s = .giallo ∨ s = .verde := s:Semaforo⊢ s = Semaforo.rosso ∨ s = Semaforo.giallo ∨ s = Semaforo.verde cases s with ⊢ Semaforo.rosso = Semaforo.rosso ∨ Semaforo.rosso = Semaforo.giallo ∨ Semaforo.rosso = Semaforo.verde ⊢ Semaforo.rosso = Semaforo.rosso All goals completed! 🐙 ⊢ Semaforo.giallo = Semaforo.rosso ∨ Semaforo.giallo = Semaforo.giallo ∨ Semaforo.giallo = Semaforo.verde ⊢ Semaforo.giallo = Semaforo.giallo ∨ Semaforo.giallo = Semaforo.verde ⊢ Semaforo.giallo = Semaforo.giallo All goals completed! 🐙 ⊢ Semaforo.verde = Semaforo.rosso ∨ Semaforo.verde = Semaforo.giallo ∨ Semaforo.verde = Semaforo.verde ⊢ Semaforo.verde = Semaforo.giallo ∨ Semaforo.verde = Semaforo.verde ⊢ Semaforo.verde = Semaforo.verde All goals completed! 🐙

3. I nostri numeri naturali

Definiamo un tipo di naturali senza usare Nat:

inductive Naturale where
  | zero
  | succ (n : Naturale)
def uno : Naturale := succ zero
def due : Naturale := succ uno
def tre : Naturale := succ due

zero è un naturale. Se n è un naturale, succ n è un naturale. Ogni valore finito di Naturale è una catena di succ che termina con zero.

4. Ricorsione

Una definizione ricorsiva risolve un problema usando il risultato dello stesso problema su un dato più semplice. Per Naturale distinguiamo il caso zero e il caso succ n.

def somma (m n : Naturale) : Naturale := match n with | zero => m | succ n => succ (somma m n)
def doppio (n : Naturale) : Naturale := match n with | zero => zero | succ n => succ (succ (doppio n))

match n with indica che somma analizza il secondo argomento. Nel caso succ n, la chiamata ricorsiva procede sul naturale più piccolo n. Lean accetta la definizione perché ogni chiamata ricorsiva si avvicina a un caso base.

5. Computazione, rfl e unfold

Due espressioni sono definizionalmente uguali quando Lean può ridurle fino alla stessa espressione. In questi casi rfl chiude il goal:

example : somma uno uno = due := ⊢ somma uno uno = due All goals completed! 🐙
theorem lecture06_somma_zero_destra (m : Naturale) : somma m zero = m := m:Naturale⊢ somma m zero = m All goals completed! 🐙
theorem lecture06_somma_succ_destra (m n : Naturale) : somma m (succ n) = succ (somma m n) := m:Naturalen:Naturale⊢ somma m n.succ = (somma m n).succ All goals completed! 🐙
theorem lecture06_doppio_succ (n : Naturale) : doppio (succ n) = succ (succ (doppio n)) := n:Naturale⊢ doppio n.succ = (doppio n).succ.succ All goals completed! 🐙

unfold rende esplicitamente visibile una definizione nel goal:

example : doppio uno = due := ⊢ doppio uno = due ⊢ (match uno with | zero => zero | n.succ => (doppio n).succ.succ) = due ⊢ (match zero.succ with | zero => zero | n.succ => (doppio n).succ.succ) = uno.succ All goals completed! 🐙

6. Riscrivere con rw

Se abbiamo h : a = b, rw [h] sostituisce a con b nel goal. rw [← h] usa la stessa uguaglianza nella direzione opposta.

theorem lecture06_rw_avanti (a b : Naturale) (h : a = b) : somma a zero = b := a:Naturaleb:Naturaleh:a = b⊢ somma a zero = b a:Naturaleb:Naturaleh:a = b⊢ somma b zero = b All goals completed! 🐙

Dopo la riscrittura il lato sinistro è somma b zero, che si riduce a b. Nel verso opposto, se h : a = b, rw [← h] trasforma somma b zero = a in somma a zero = a.

theorem lecture06_rw_indietro (a b : Naturale) (h : a = b) : somma b zero = a := a:Naturaleb:Naturaleh:a = b⊢ somma b zero = a a:Naturaleb:Naturaleh:a = b⊢ somma a zero = a All goals completed! 🐙

7. Induzione

somma m zero = m si riduce subito: il secondo argomento è esplicitamente zero. Nell'enunciato somma zero n = n, invece, n è una variabile. Lean non sa ancora se n sia zero oppure succ k, e non può scegliere una riga della definizione di somma.

Non basta controllare alcuni valori, perché il risultato deve valere per tutti i naturali. Una dimostrazione per induzione ha un caso base per zero e un passo induttivo: assumiamo il risultato per n e lo dimostriamo per succ n. L'assunzione del passo è l'ipotesi induttiva.

Nel passo usiamo rewrite [ih]. Come rw [ih], sostituisce con l'ipotesi induttiva. Qui però lascia visibile il goal finale, che chiudiamo esplicitamente con rfl. rw può chiudere da solo un goal che, dopo la riscrittura, ha la forma t = t.

theorem lecture06_zero_somma (n : Naturale) : somma zero n = n := n:Naturale⊢ somma zero n = n induction n with ⊢ somma zero zero = zero All goals completed! 🐙 n:Naturaleih:somma zero n = n⊢ somma zero n.succ = n.succ n:Naturaleih:somma zero n = n⊢ (somma zero n).succ = n.succ n:Naturaleih:somma zero n = n⊢ n.succ = n.succ All goals completed! 🐙

Scegliamo la variabile d'induzione osservando la definizione ricorsiva. Qui somma analizza il secondo argomento, quindi nel goal somma zero n = n facciamo induzione su n.

La stessa scelta vale per un goal con due argomenti, come somma (succ m) n = succ (somma m n): il secondo argomento di entrambe le somme è n, quindi facciamo induzione su n.

theorem lecture06_succ_somma (m n : Naturale) : somma (succ m) n = succ (somma m n) := m:Naturalen:Naturale⊢ somma m.succ n = (somma m n).succ induction n with m:Naturale⊢ somma m.succ zero = (somma m zero).succ All goals completed! 🐙 m:Naturalen:Naturaleih:somma m.succ n = (somma m n).succ⊢ somma m.succ n.succ = (somma m n.succ).succ m:Naturalen:Naturaleih:somma m.succ n = (somma m n).succ⊢ (somma m.succ n).succ = (somma m n).succ.succ m:Naturalen:Naturaleih:somma m.succ n = (somma m n).succ⊢ (somma m n).succ.succ = (somma m n).succ.succ All goals completed! 🐙

8. Associatività, commutatività e simp

Per l'associatività scegliamo c, il secondo argomento della somma esterna:

theorem lecture06_somma_assoc (a b c : Naturale) : somma (somma a b) c = somma a (somma b c) := a:Naturaleb:Naturalec:Naturale⊢ somma (somma a b) c = somma a (somma b c) induction c with a:Naturaleb:Naturale⊢ somma (somma a b) zero = somma a (somma b zero) All goals completed! 🐙 a:Naturaleb:Naturalec:Naturaleih:somma (somma a b) c = somma a (somma b c)⊢ somma (somma a b) c.succ = somma a (somma b c.succ) a:Naturaleb:Naturalec:Naturaleih:somma (somma a b) c = somma a (somma b c)⊢ (somma (somma a b) c).succ = somma a (somma b c.succ) a:Naturaleb:Naturalec:Naturaleih:somma (somma a b) c = somma a (somma b c)⊢ (somma (somma a b) c).succ = somma a (somma b c).succ a:Naturaleb:Naturalec:Naturaleih:somma (somma a b) c = somma a (somma b c)⊢ (somma (somma a b) c).succ = (somma a (somma b c)).succ All goals completed! 🐙

La commutatività non segue soltanto dalla computazione: somma non tratta simmetricamente i due argomenti. Nel caso base usiamo zero_somma. Nel passo usiamo succ_somma per spostare il successore dal primo argomento.

theorem lecture06_somma_comm (a b : Naturale) : somma a b = somma b a := a:Naturaleb:Naturale⊢ somma a b = somma b a induction b with a:Naturale⊢ somma a zero = somma zero a a:Naturale⊢ somma a zero = a All goals completed! 🐙 a:Naturaleb:Naturaleih:somma a b = somma b a⊢ somma a b.succ = somma b.succ a a:Naturaleb:Naturaleih:somma a b = somma b a⊢ (somma a b).succ = somma b.succ a a:Naturaleb:Naturaleih:somma a b = somma b a⊢ (somma a b).succ = (somma b a).succ All goals completed! 🐙

simp automatizza riscritture orientate verso forme più semplici. simp only [lemmi] limita esplicitamente le regole usate. simp [lemma] aggiunge una regola per quel comando. attribute [local simp] lemma la rende disponibile nella sezione corrente.

theorem lecture06_zero_somma_con_rw (n : Naturale) : somma zero n = n := n:Naturale⊢ somma zero n = n All goals completed! 🐙
theorem lecture06_zero_somma_con_simp_only (n : Naturale) : somma zero n = n := n:Naturale⊢ somma zero n = n All goals completed! 🐙
theorem lecture06_zero_somma_con_simp (n : Naturale) : somma zero n = n := n:Naturale⊢ somma zero n = n All goals completed! 🐙
theorem lecture06_succ_somma_con_simp (m n : Naturale) : somma (succ m) n = succ (somma m n) := m:Naturalen:Naturale⊢ somma m.succ n = (somma m n).succ All goals completed! 🐙
@[simp] theorem lecture06_doppio_zero : doppio zero = zero := ⊢ doppio zero = zero All goals completed! 🐙

@[simp] registra una regola per il resto del modulo. Lo usiamo per una regola canonica come doppio zero = zero. Associatività e commutatività non sono regole adatte al simp-set: cambiano soltanto il raggruppamento o l'ordine degli argomenti.

9. Una dimostrazione conclusiva

Combiniamo induzione e riscritture per dimostrare che il doppio di una somma è la somma dei doppi. La sottoespressione che resta bloccata è somma m n, perciò facciamo induzione su n.

theorem lecture06_doppio_somma (m n : Naturale) : doppio (somma m n) = somma (doppio m) (doppio n) := m:Naturalen:Naturale⊢ doppio (somma m n) = somma (doppio m) (doppio n) induction n with m:Naturale⊢ doppio (somma m zero) = somma (doppio m) (doppio zero) All goals completed! 🐙 m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ doppio (somma m n.succ) = somma (doppio m) (doppio n.succ) m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ doppio (somma m n).succ = somma (doppio m) (doppio n.succ) m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ (doppio (somma m n)).succ.succ = somma (doppio m) (doppio n.succ) m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ (doppio (somma m n)).succ.succ = somma (doppio m) (doppio n).succ.succ m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ (doppio (somma m n)).succ.succ = (somma (doppio m) (doppio n).succ).succ m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ (doppio (somma m n)).succ.succ = (somma (doppio m) (doppio n)).succ.succ All goals completed! 🐙

Dopo avere verificato ogni passaggio, possiamo esprimere la stessa dimostrazione con un insieme controllato di regole di semplificazione:

theorem lecture06_doppio_somma_breve (m n : Naturale) : doppio (somma m n) = somma (doppio m) (doppio n) := m:Naturalen:Naturale⊢ doppio (somma m n) = somma (doppio m) (doppio n) induction n with m:Naturale⊢ doppio (somma m zero) = somma (doppio m) (doppio zero) All goals completed! 🐙 m:Naturalen:Naturaleih:doppio (somma m n) = somma (doppio m) (doppio n)⊢ doppio (somma m n.succ) = somma (doppio m) (doppio n.succ) All goals completed! 🐙

10. Strategia operativa

1. Individuiamo i costruttori del tipo. 2. Leggiamo quale argomento è analizzato dalla definizione. 3. Proviamo se il goal si riduce con rfl. 4. Usiamo con rw le uguaglianze già dimostrate. 5. Se resta una variabile nell'argomento analizzato, scegliamo quella variabile per l'induzione. 6. Automatizziamo con simp only o simp.
